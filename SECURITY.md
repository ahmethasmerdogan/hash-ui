# Security

HashUI is a client-side design system: components, tokens and a stylesheet.
It has no server, holds no credentials and makes no network requests of its
own — with three exceptions, all opt-in and all documented below.

## Reporting a vulnerability

Please **do not open a public issue**. Email
[a.erdogan6868@gmail.com](mailto:a.erdogan6868@gmail.com) with what you found
and how to reproduce it. You will get an acknowledgement within a few days.

## What is supported

The latest minor release of each package. There are no long-term support
branches yet.

| Package | Supported |
| --- | --- |
| `hash-ui` | 0.6.x |
| `hash-ui-blocks` | 0.6.x |

## What reaches the network

`hash-ui` reaches nothing. Three blocks in `hash-ui-blocks` do, each behind an
optional peer you have to install yourself:

| Block | Peer | Fetches |
| --- | --- | --- |
| `SplineScene` / `SplineHero` | `@splinetool/react-spline` | the scene URL you pass |
| `GlobeFlights` | `cobe` | nothing — the map data is embedded |
| `Map` and its markers | `maplibre-gl` | the tile server in the style you pass |

`Map` defaults to CARTO's public raster tiles so the block works without an API
key. Pass your own `style` to point it somewhere you control.

The `LogoCloud` **demo content** references wordmarks on `svgl.app`. That is
demo data, not behaviour: pass your own `logos` and nothing third-party is
requested.

## Copying the source in

The shadcn registry at `hashui.vercel.app/r/*.json` serves the same source that
is in this repository, generated by `scripts/build-registry.mjs` at build time.
Nothing is minified or obfuscated — read it before you run it, as you would
with any `npx` command.
